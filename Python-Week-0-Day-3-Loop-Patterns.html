Part 02 · The new idea

Nested loops

A nested loop is simply a loop inside another loop. The inner loop runs all the way through on every single pass of the outer loop.

For patterns, think of it as rows and columns. The outer loop picks the row. The inner loop fills that row, left to right.

main.py
for row in range(3):          # 3 rows (outer loop)
    for col in range(4):      # 4 stars per row (inner loop)
        print("*", end="")  # end="" keeps stars on the SAME line
    print()                    # empty print() moves to the next row

Output:
****
****
****

Two small tools do all the work here:

Remember these two

print("*", end="") prints without jumping to a new line, so a row stays together. An empty print() after the inner loop ends the row and starts the next one. Forget either and your pattern falls apart.

The key move for triangles

The inner loop's count does not have to be fixed. If it depends on the outer row number, you get a growing shape:

main.py
for i in range(1, 6):       # rows 1, 2, 3, 4, 5
    for j in range(i):     # row 1 gets 1 star, row 2 gets 2 ...
        print("*", end="")
    print()

Output:
*
**
***
****
*****

Key idea

Outer loop = rows. Inner loop = what goes in each row. Make the inner count depend on the row number, and shapes appear.

Example 1

A 5 × 5 square

The simplest nested loop: a fixed number of stars on a fixed number of rows.

main.py
for row in range(5):
    for col in range(5):
        print("*", end="")
    print()

Output:
*****
*****
*****
*****
*****

Example 2

A pyramid

A pyramid adds one new thing: spaces before the stars, so each row is centered. Each row has two inner loops, one for spaces, one for stars.

main.py
n = 5
for i in range(1, n + 1):
    for s in range(n - i):       # spaces: 4, then 3, then 2 ...
        print(" ", end="")
    for j in range(2 * i - 1):   # stars: 1, 3, 5, 7, 9
        print("*", end="")
    print()

Output:
    *
   ***
  *****
 *******
*********

Shortcut worth knowing

The same pyramid in one line per row, using string multiplication: print(" " * (n - i) + "*" * (2 * i - 1)). Both are correct. The nested version shows what is really happening; the shortcut is cleaner once you understand it.

Part 04

Common mistakes

Almost every broken pattern is one of these three.

1 · Forgetting end=""

Without end="", every star jumps to its own line and you get a vertical column instead of a row.

2 · Forgetting the empty print()

Without print() after the inner loop, every row runs together into one long line.

3 · Wrong number of spaces

In centered shapes, the spaces must shrink as the stars grow. Get the count wrong and the pyramid leans to one side.
