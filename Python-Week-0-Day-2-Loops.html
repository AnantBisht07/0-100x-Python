Part 01

What a loop really does

A loop runs the same block of code more than once, so you never repeat yourself by hand.

There are two loops, and choosing the right one is most of the skill.

LoopUse it whenShape
forYou know what you're looping over (a range, list, or string)for x in something:
whileYou loop until a condition changeswhile condition:

range() is where beginners trip

Most for loops use range(). Read these four carefully; they cover almost everything:

range cheat sheet
range(5)            # 0, 1, 2, 3, 4   (starts at 0, stops BEFORE 5)
range(1, 6)         # 1, 2, 3, 4, 5
range(2, 11, 2)     # 2, 4, 6, 8, 10  (third number = step)
range(10, 0, -1)    # 10 down to 1    (negative step counts down)

A basic for loop and the same logic as a while loop:

main.py
# for: print 1 to 5
for i in range(1, 6):
    print(i)

# while: the same result, written by hand
i = 1
while i <= 5:
    print(i)
    i += 1      # without this line, the loop never ends
Key idea

Use for when you know how many times or what you're iterating. Use while when you're waiting for a condition to flip.

Part 02

Looping over data

A for loop walks through any sequence one item at a time. You don't need indexes for this.

main.py
# loop over a list
for price in [120, 50, 90]:
    print(price)

# loop over a string, one character at a time
for letter in "python":
    print(letter)

The variable name (price, letter) is yours to choose. On each pass it holds the next item. That is the whole concept.

Part 03

The accumulator pattern

This is the most useful loop habit you will learn. Master it and most loop problems become easy.

The pattern: create a variable before the loop, then update it inside the loop on every pass.

main.py
# SUM: add up numbers
total = 0                 # start before the loop
for n in [4, 8, 15]:
    total += n            # update each pass (total = total + n)
print(total)              # 27

# COUNT: count things works the same way
count = 0
for n in [4, 8, 15]:
    count += 1
print(count)              # 3
Watch the placement

If you put total = 0 inside the loop, it resets to zero on every pass and your answer is always wrong. The starting value goes above the loop.

Part 04

break, continue & common mistakes

Two keywords let you steer a loop, and four mistakes catch almost every beginner.

KeywordWhat it does
breakExits the loop immediately, right now.
continueSkips the rest of this pass and jumps to the next one.

1 · Off-by-one

range(1, 10) stops at 9, not 10. To include 10, write range(1, 11).

2 · Infinite while loop

If the condition variable never changes inside a while, the loop runs forever. Always update it (e.g. i += 1).

3 · Resetting the accumulator

Putting total = 0 inside the loop wipes your running total every pass. Keep it above the loop.

4 · Indentation

Code must be indented to be "inside" the loop. Code at the left margin runs only once, after the loop finishes.

Worked examples

Example 1

Sum of numbers from 1 to n

Add up every number from 1 up to n. This is the accumulator pattern over a range.

main.py
n = 10
total = 0
for number in range(1, n + 1):   # 1 to n, so stop at n+1
    total += number
print(total)

Output: 55

Why n + 1? Because range stops one short. To include n, the stop value must be one past it.

Example 2

Count the vowels in a word

Walk through each letter, and count it only if it is a vowel. This combines string iteration, a condition, and a counter.

main.py
word = "education"
count = 0
for letter in word:
    if letter in "aeiou":        # is this letter a vowel?
        count += 1
print(count)

Output: 5

letter in "aeiou" is True when the letter is one of those five characters. Only then do we add to the count.
